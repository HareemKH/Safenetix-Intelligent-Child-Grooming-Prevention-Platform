# Intelligent Child Grooming Prevention Platform
This repository is the central workspace for our Final Year Project (FYP).

All team members will use this repository to upload, manage, and collaborate on project-related work, including code, research, documentation, and other deliverables.

Repository Guidelines
Upload your work to the appropriate folders.
Keep files organized and properly named.
Use separate branches for your contributions.
Commit and push changes regularly.
Keep the main branch clean and updated.
